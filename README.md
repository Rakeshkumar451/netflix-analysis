# 🎬 Netflix Content Analysis

## 📌 Overview
Analysis of Netflix's movies and TV shows catalog using Python.

## 🛠 Tools Used
- Python (pandas, matplotlib, seaborn)
- VS Code + Jupyter

## 📊 Key Questions Answered
1. Movies vs TV Shows split
2. Content growth over the years
3. Top content-producing countries
4. Most common genres
5. Rating distribution

## 🔍 Key Insights
- Netflix is ~70% Movies, ~30% TV Shows
- Content additions peaked in 2019
- USA, India, and UK lead production
- Dramas and Comedies dominate genres
- Netflix targets mature audiences (TV-MA, TV-14)

## 🚀 How to Run
1. Clone the repo
2. Create venv: `python -m venv venv`
3. Activate: `venv\Scripts\activate` (Windows) or `source venv/bin/activate`
4. Install deps: `pip install -r requirements.txt`
5. Open `netflix_analysis.ipynb` in VS Code
6. Click "Run All"
